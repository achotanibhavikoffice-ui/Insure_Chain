# Smart Contracts

## `LifeInsurancePolicy.sol`

Main application contract. It creates policies for the connected wallet and accepts a Groth16 proof. It checks that the proof's public threshold values match the policy and then calls the verifier.

If the verifier returns `true`, the policy moves from `Pending` to `Active` automatically.

## `MockZKPVerifier.sol`

Development-only contract. It is NOT a cryptographic verifier. It is useful for demonstrating the end-to-end UI/transaction flow before generating the real verifier.

## `Groth16Verifier.sol`

This file is intentionally generated by `npm run zkp:setup` using `snarkjs zkey export solidityverifier`. Do not hand-write or modify it. The generated verifier is tied to the exact circuit and proving key.
